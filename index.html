2. Теорія та приклади HTML

Нижче наведено опрацьовані приклади з підручника w3schoolsua за кожним підпунктом: короткий конспект, результат у браузері та HTML-код.

2.1. Що таке HTML?

HTML (HyperText Markup Language) — стандартна мова розмітки для створення веб-сторінок. Вона описує структуру сторінки за допомогою елементів, які браузер відображає як заголовки, абзаци, посилання тощо. <!DOCTYPE html> оголошує документ HTML5, <html> — кореневий елемент, <head> містить метаінформацію, <title> — назву сторінки, <body> — видимий вміст.

HTML-код:
<!DOCTYPE html>
<html lang="uk">
<head>
  <meta charset="UTF-8">
  <title>Заголовок сторінки</title>
</head>
<body>
  <h1>Мій перший заголовок</h1>
  <p>Мій перший абзац.</p>
</body>
</html>

  • Visual Studio Code (з розширенням Live Server) — використовується в цій роботі;
  • WebStorm;

Файл зберігають з розширенням .html у кодуванні UTF-8 і відкривають у браузері.

2.4. HTML Елементи

Елемент HTML — це все від початкового до кінцевого тегу: <тег>вміст</тег>. Елементи можуть бути вкладеними. Деякі елементи порожні (не мають вмісту і закриваючого тегу), напр. <br>, <hr>, <img>. HTML не чутливий до регістру, але рекомендовано писати теги малими літерами.

<div>
  <p>Абзац усередині <strong>div</strong>,
  а в ньому <em>вкладений</em> елемент <b>b</b>.</p>
  <p>Розрив рядка:<br>новий рядок</p>
</div>

Атрибути надають додаткову інформацію про елемент і записуються в початковому тезі у вигляді name="value". Основні: href, src, width/height, alt, style, lang, title.

<p><img src="images/phone.svg" alt="Смартфон" width="100" height="80"></p>

<p title="Я — підказка">Наведіть курсор на цей абзац (атрибут title)</p>

2.6. HTML Параграфи

<p> — абзац; браузер автоматично додає відступи та ігнорує зайві пробіли і переноси. <hr> — горизонтальна лінія (тематичний розрив), <br> — розрив рядка, <pre> — попередньо форматований текст, у якому пробіли й переноси зберігаються.

2.7. HTML Посилання

Гіперпосилання створюються тегом <a>; атрибут href задає адресу. Атрибут target визначає, де відкрити документ: _self (за замовчуванням), _blank (нова вкладка), _parent, _top. Посилання бувають абсолютні (повний URL) і відносні (у межах сайту). Зображення теж може бути посиланням. mailto: відкриває поштову програму.

Результат:

HTML-код:
<p><a href="https://w3schoolsua.github.io/" target="_blank">Абсолютне посилання (нова вкладка)</a></p>
<p><a href="index.html">Відносне посилання на цю ж сторінку</a></p>
<p><a href="https://w3schoolsua.github.io/"><img src="images/logo.svg" alt="Посилання-зображення" width="40" height="40"></a> — зображення як посилання</p>
<p><a href="mailto:student@example.com">Надіслати лист</a></p>
<p><button onclick="document.location='#p2-9'">Кнопка-посилання до таблиць</button></p>

2.7.1. HTML Посилання — різні кольори

За замовчуванням непереглянуте посилання синє і підкреслене, переглянуте — фіолетове, активне — червоне. Кольори змінюються CSS-псевдокласами :link, :visited, :hover, :active. Посилання можна оформити як кнопку.

Результат:

Наведіть курсор на посилання

Посилання-кнопка
HTML-код:
<style>
  .colors a:link    { color: green; text-decoration: none; }
  .colors a:visited { color: pink; }
  .colors a:hover   { color: red; text-decoration: underline; }
  .colors a:active  { color: yellow; }
  a.btn-link { background: #f44336; color: white; padding: 10px 20px;
               text-decoration: none; display: inline-block; border-radius: 4px; }
  a.btn-link:hover { background: #c62828; }
</style>
<p class="colors"><a href="https://w3schoolsua.github.io/" target="_blank">Наведіть курсор на посилання</a></p>
<a class="btn-link" href="https://w3schoolsua.github.io/" target="_blank">Посилання-кнопка</a>

2.8. HTML Зображення

2.8.1. HTML Карти зображень

Тег <map> визначає карту зображення з активними (клікабельними) областями <area>. Зображення зв'язується з картою атрибутом usemap="#ім'я". Форми областей (shape): rect, circle, poly, default; coords — координати.

Результат:

Клікніть на жовте коло або на ліву частину банера.

HTML-код:
<img src="images/banner.svg" alt="Банер" usemap="#bannermap" width="450" height="130">
<map name="bannermap">
  <area shape="rect"   coords="0,0,330,130" alt="Акція" href="#p2-8" title="Ліва частина: до розділу зображень">
  <area shape="circle" coords="380,65,45"   alt="Знижка" href="#p2-9" title="Коло: до розділу таблиць">
</map>
<p>Клікніть на жовте коло або на ліву частину банера.</p>

2.8.2. HTML Фонові зображення

Фонове зображення задається CSS-властивістю background-image. Повторення регулює background-repeat, масштаб — background-size (cover, contain, 100% 100%), фіксацію — background-attachment.

Результат:
Блок із повторюваним фоном (background-repeat: repeat)
HTML-код:
<div style="background-image:url('images/watch.svg'); background-repeat:repeat; background-size:80px 64px;
            height:130px; padding:10px; color:#fff; font-weight:bold;">
  Блок із повторюваним фоном (background-repeat: repeat)
</div>
<div style="background-image:url('images/banner.svg'); background-size:cover; height:100px; margin-top:8px;"></div>

2.8.3. HTML елемент <picture>

Елемент <picture> дозволяє вказати кілька джерел зображення (<source>) з умовами media або різними форматами (type). Браузер обирає перше відповідне, а <img> наприкінці — запасний варіант. Змініть ширину вікна, щоб побачити різні зображення.

Результат:
HTML-код:
<picture>
  <source media="(min-width: 1000px)" srcset="images/laptop.svg">
  <source media="(min-width: 600px)"  srcset="images/watch.svg">
  <img src="images/phone.svg" alt="Адаптивне зображення" width="200" height="160">
</picture>

2.8.4. HTML Favicon / Фавікон

Фавікон — маленька іконка біля назви сторінки на вкладці браузера. Підключається в <head> тегом <link rel="icon">; підтримуються формати ICO, PNG, GIF, JPEG, SVG. Ця сторінка має фавікон — подивіться на її вкладку.

HTML-код:
<head>
  <title>Самостійні роботи</title>
  <link rel="icon" type="image/svg+xml" href="images/logo.svg">
</head>

2.9. HTML Таблиці

Таблиця створюється тегом <table>; рядки — <tr>, комірки-заголовки — <th>, комірки з даними — <td>. Комірка може містити будь-які елементи: текст, зображення, списки, інші таблиці.

Rozetka Олена Коваль Україна
Comfy Петро Шевчук Україна

<table>

    <th>Компанія</th>
    <th>Контакт</th>
    <th>Країна</th>
  </tr>
  <tr>
    <td>Rozetka</td>
    <td>Олена Коваль</td>
    <td>Україна</td>
  </tr>
  <tr>
    <td>Comfy</td>
    <td>Петро Шевчук</td>
    <td>Україна</td>
  </tr>

2.9.1. HTML Межі таблиці

Межі задаються CSS-властивістю border. Щоб уникнути подвійних меж, використовують border-collapse: collapse. Можна задати колір, стиль (dotted, dashed, double…), закруглені кути (border-radius) або лише нижні межі.

Результат:
Ім'яВік
Іван19

Пунктирнімежі
HTML-код:
<table style="border:1px solid black; border-collapse:collapse;">
  <tr><th style="border:1px solid black;">Ім'я</th><th style="border:1px solid black;">Вік</th></tr>
  <tr><td style="border:1px solid black;">Іван</td><td style="border:1px solid black;">19</td></tr>
</table>
<br>
<table style="border:3px dashed #2b59c3; border-radius:10px;">
  <tr><th style="border:2px dotted green; border-radius:6px;">Пунктирні</th><th style="border:2px dotted green; border-radius:6px;">межі</th></tr>
</table>

2.9.2. HTML Розмір таблиці

Ширину таблиці, стовпця та висоту рядка задають CSS-властивостями width і height (у відсотках або пікселях).

Результат:
Стовпець 70% Решта
Рядок висотою 60px ...
HTML-код:
<table style="width:100%; border:1px solid #999; border-collapse:collapse;">
  <tr>
    <th style="width:70%; border:1px solid #999;">Стовпець 70%</th>
    <th style="border:1px solid #999;">Решта</th>
  </tr>
  <tr style="height:60px;">
    <td style="border:1px solid #999;">Рядок висотою 60px</td>
    <td style="border:1px solid #999;">...</td>
  </tr>
</table>

2.9.3. HTML Заголовки таблиць

Заголовки (<th>) можуть бути в першому рядку (для стовпців) або в першому стовпці (для рядків). За замовчуванням вони жирні та по центру; вирівнювання змінюють text-align. Заголовок може охоплювати кілька стовпців (colspan). Підпис таблиці — <caption>.

Результат:
Розклад на тиждень
ПонеділокHTMLCSS
ВівторокJavaScriptGit
Заголовок на 3 стовпці, вирівняний ліворуч
HTML-код:
<table style="border-collapse:collapse;" border="1">
  <caption>Розклад на тиждень</caption>
  <tr><th>Понеділок</th><td>HTML</td><td>CSS</td></tr>
  <tr><th>Вівторок</th><td>JavaScript</td><td>Git</td></tr>
  <tr><th colspan="3" style="text-align:left;">Заголовок на 3 стовпці, вирівняний ліворуч</th></tr>
</table>

2.9.4. HTML Таблиці. Padding & Spacing

Padding — відступ між вмістом комірки та її межею (CSS padding). Spacing — відстань між комірками (CSS border-spacing, діє без border-collapse).

Результат:
padding 15px border-spacing 12px
HTML-код:
<table style="border:1px solid black; border-spacing:12px;">
  <tr>
    <td style="border:1px solid black; padding:15px;">padding 15px</td>
    <td style="border:1px solid black; padding:15px;">border-spacing 12px</td>
  </tr>
</table>

2.9.5. HTML Таблиці. Colspan & Rowspan

colspan об'єднує комірку на кілька стовпців, rowspan — на кілька рядків.

Результат:

ТарасБульба43
Телефон050-111-22-33
067-444-55-66
HTML-код:
<table border="1" style="border-collapse:collapse;" cellpadding="6">
  <tr><th colspan="2">Ім'я та прізвище</th><th>Вік</th></tr>
  <tr><td>Тарас</td><td>Бульба</td><td>43</td></tr>
  <tr><th rowspan="2">Телефон</th><td colspan="2">050-111-22-33</td></tr>
  <tr><td colspan="2">067-444-55-66</td></tr>
</table>

2.9.6. HTML Стилізація таблиць

Таблицю «зебра» створюють селектором :nth-child(even), вертикальну «зебру» — :nth-child(even) для комірок, горизонтальні роздільники — border-bottom, підсвічування рядка при наведенні — tr:hover.

Результат:
ТоварЦіна
Смартфон12 999 грн
Ноутбук32 499 грн
Навушники2 799 грн
Годинник4 599 грн
HTML-код:
<style>
  .zebra { border-collapse: collapse; width: 100%; }
  .zebra th, .zebra td { padding: 8px; border-bottom: 1px solid #ddd; text-align: left; }
  .zebra tr:nth-child(even) { background-color: #e8eefc; }
  .zebra tr:hover { background-color: #ffe08a; }
</style>
<table class="zebra">
  <tr><th>Товар</th><th>Ціна</th></tr>
  <tr><td>Смартфон</td><td>12 999 грн</td></tr>

2.10. HTML Списки

HTML має три види списків: невпорядкований <ul>, впорядкований <ol> та список описів <dl>. Кожен пункт <ul>/<ol> — <li>.

Результат:
  • Кава
  • Чай
  1. Кава
  2. Чай
HTML-код:
<ul>
  <li>Кава</li>
  <li>Чай</li>
</ul>
<ol>
  <li>Кава</li>
  <li>Чай</li>
</ol>

2.10.1. HTML Невпорядковані списки

Вид маркера задає CSS list-style-type: disc, circle, square, none. Списки можуть бути вкладеними. Горизонтальний список (меню) отримують через display:inline або flex.

<ul style="list-style-type:square;">

2.10.2. HTML Впорядковані списки

Атрибут type визначає вид нумерації: 1, A, a, I, i. Атрибут start — початкове значення. Списки можна вкладати.

3. HTML Форми

Самостійно вивчено компонент «Форми» та відпрацьовано приклади з усіх підрозділів.

3.1. HTML Форми

Елемент <form> — контейнер для елементів введення, що збирають дані користувача. Найпоширеніший елемент — <input>, тип якого визначає атрибут type. <label> — підпис поля (атрибут for = id поля). Кожне поле повинно мати атрибут name, інакше його значення не буде надіслане.

Результат:








HTML-код:
<form action="#" method="get">
  <label for="fname">Ім'я:</label><br>
  <input type="text" id="fname" name="fname" value="Тарас"><br>
  <label for="lname">Прізвище:</label><br>
  <input type="text" id="lname" name="lname" value="Бульба"><br><br>
  <input type="radio" id="html" name="lang" value="HTML" checked>
  <label for="html">HTML</label>
  <input type="radio" id="css" name="lang" value="CSS">
  <label for="css">CSS</label><br>
  <input type="checkbox" id="bike" name="v1" value="Bike">
  <label for="bike">У мене є велосипед</label><br><br>
  <input type="submit" value="Надіслати">
</form>

3.1.1. HTML Атрибути форми

action — адреса обробника даних; target — де показати відповідь (_blank, _self…); method — get (дані в URL) або post (дані в тілі запиту); autocomplete — on/off; novalidate — вимикає перевірку; enctype, name, rel, accept-charset.

Результат:
HTML-код:
<form action="https://www.w3schools.com/action_page.php" method="get" target="_blank" autocomplete="on">
  <label for="email1">E-mail:</label>
  <input type="email" id="email1" name="email">
  <input type="submit" value="Надіслати (GET, нова вкладка)">
</form>
<form action="#" novalidate>
  <input type="email" name="email2" placeholder="без перевірки (novalidate)">
  <input type="submit">
</form>

Елементи форми: <input>, <label>, <select> з <option> та <optgroup>, <textarea>, <button>, <fieldset> і <legend>, <datalist> (підказки для input), <output> (результат обчислень).

3.1.4. HTML Атрибути вводу

Атрибути <input>: value (початкове значення), readonly (лише читання), disabled (вимкнене), size, maxlength, min/max, multiple, pattern, placeholder, required, step, autofocus, height/width (для type="image"), list, autocomplete.

3.1.5. HTML Атрибути Input форми

Атрибут form пов'язує поле з формою, навіть якщо воно знаходиться поза нею. Атрибути formaction, formenctype, formmethod, formtarget, formnovalidate для кнопок submit перевизначають відповідні атрибути форми; novalidate — атрибут самої форми.

5. HTML5

HTML5 — остання версія стандарту HTML.
